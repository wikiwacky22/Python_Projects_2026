# Python_Projects_2026
This is a collection of my favorite projects during my 2026 coding year.
mockcreate (1).py: A interactive program designed to help users choose a dog breed that matches their needs. It allows users to filter dog breeds by size (tiny, small, medium, or large), specific breed names, or desired traits/purposes. The script utilizes data from an accompanying dogs.csv file.  boardgamepicker.py: A recommendation application that finds board games based on user inputs such as available play time, preferred game mechanics (e.g., 'Trading', 'Dice Rolling'), number of players, and categories (e.g., 'Fantasy', 'Animals'). It draws information from a games.csv dataset.  slotmachine.py: A slot machine simulation developed by Perrin and Caleb. It features a credit loading system and a persistent scoreboard that tracks the "Top 5 Money Makers" by reading from and writing to a scoreboard.txt file. It also includes a simulation mode to calculate house profit over a set number of spins.  calculator.py: A simple command-line calculator that performs basic arithmetic operations. It prompts users for two numbers and an operator (+, -, /, *) to return the sum, difference, quotient, or product.  nickname.py: A "Marvel character picker" that functions as a nickname generator. It uses a series of branching logic questions—asking about traits like "magical vs. metal" or "young vs. old"—to assign the user a specific Marvel hero, such as Scarlet Witch, Iron Man, or Spider-Man.
